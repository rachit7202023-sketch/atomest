# Handoff & Recurring Maintenance Process

**Purpose:** How Atomest hands off a completed project to the client, and what ongoing maintenance looks like.  
**Principle:** The client owns their systems. Atomest provides documentation, training, and optional ongoing support.

---

## 1. Handoff package

Delivered to the client at launch:

| Item | Description |
|------|-------------|
| System overview | Plain-language explanation of what was built and how it works |
| Credential inventory | Where each credential is stored, who owns it, how to rotate |
| Access documentation | URLs for Vercel, Supabase, n8n, CRM, calendar, Slack |
| Runbook | Common issues and how to resolve them (call not ringing, form not submitting, etc.) |
| Escalation contact | Atomest contact for urgent issues, response time commitment |
| Training | 60–90 minute handoff call with screen share, recorded for reference |

## 2. Knowledge transfer

- Client admin is walked through each system
- Client performs one test action themselves (e.g., submits a test lead, makes a test call)
- Client confirms they can access all dashboards
- Questions answered and documented

## 3. Recurring maintenance (optional, monthly retainer)

If the client signs up for maintenance, Atomest provides:

| Task | Frequency |
|------|-----------|
| Review form submissions and error logs | Weekly |
| Check n8n workflow execution errors | Weekly |
| Knowledge base content refresh (Division A/D) | Monthly |
| Prompt tuning based on logs (Division A/D) | Monthly |
| Supabase credit/usage review | Monthly |
| Vercel deployment health check | Monthly |
| Security header review | Quarterly |
| API credential rotation | Semi-annually |

## 4. Maintenance pricing (guidance only; customized per client)

| Tier | Includes | Suggested Monthly |
|------|----------|-------------------|
| Basic | Error log review, form monitoring | $200–$400 |
| Standard | Basic + knowledge base updates, prompt tuning | $400–$800 |
| Premium | Standard + quarterly strategy call, priority support | $800–$1,500 |

## 5. What maintenance does NOT include

- Third-party service fees (telephony, LLM API, CRM subscriptions)
- Major new features (out of scope of original project)
- Content creation (copywriting, photography)
- 24/7 emergency response (unless separately contracted)

## 6. End of engagement

If the client does not renew maintenance:
- All documentation and credentials remain with the client
- Atomest provides a final handoff summary
- Client is responsible for renewing their own third-party subscriptions
- Atomest is available for future projects on a new statement of work
