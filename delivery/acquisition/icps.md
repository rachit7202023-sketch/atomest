# Ideal Customer Profiles (ICPs)

**Purpose:** Define who Atomest serves across its five service divisions.  
**Principle:** No fabricated prospects. These are profile templates for targeting real businesses that match the described characteristics.

---

## Division A — AI Voice Receptionist

**Primary ICP:** Local service businesses with 5–50 employees that receive phone enquiries but miss after-hours or overflow calls.

| Attribute | Profile |
|-----------|---------|
| Industries | HVAC, plumbing, electrical, dental, veterinary, legal (solo/small firm), real estate agencies, cleaning services |
| Business size | 5–50 employees, $1M–$10M annual revenue |
| Pain point | Missing after-hours calls, lost new patient/client enquiries, staff overwhelmed by phone volume |
| Current state | Voicemail only after hours, receptionist misses calls during jobs, no appointment automation |
| Trigger event | Missed call complaint, negative review about "no one answers", hiring a receptionist is too expensive |
| Decision maker | Owner, office manager, practice manager |
| Budget signal | Currently spending on advertising (Google Local Services Ads, Yelp) but losing leads to missed calls |
| Typical engagement | $1,500–$3,500 setup + $200–$500/month monitoring |

**Secondary ICP:** Professional services firms (accountants, consultants) that want to qualify callers before booking consultations.

---

## Division B — Lead Automation

**Primary ICP:** B2B service businesses generating 10–100 website enquiries per month with no systematic follow-up.

| Attribute | Profile |
|-----------|---------|
| Industries | Marketing agencies, web development agencies, IT services, coaching/consulting, solar installation, home renovation |
| Business size | 10–100 employees, $2M–$20M annual revenue |
| Pain point | Leads fall through cracks, slow response time, no CRM integration, manual data entry |
| Current state | Contact form emails to a shared inbox, someone checks once a day, leads go cold |
| Trigger event | Lost a big deal due to slow follow-up, hiring a salesperson but no process to feed them |
| Decision maker | Owner, head of sales, operations manager |
| Budget signal | Using paid ads (LinkedIn, Google Ads) and paying for leads that aren't followed up |
| Typical engagement | $2,000–$5,000 setup + $300–$700/month maintenance |

**Secondary ICP:** E-commerce brands with high cart abandonment and no win-back automation.

---

## Division C — CRM & Workflow Automation

**Primary ICP:** Professional practices using multiple disconnected tools (website, email, accounting, calendar) with manual data movement between them.

| Attribute | Profile |
|-----------|---------|
| Industries | Accounting firms, law firms, architecture studios, design agencies, recruitment agencies |
| Business size | 10–200 employees, $3M–$50M annual revenue |
| Pain point | Client data entered twice, onboarding tasks forgotten, overdue items not flagged, no single client view |
| Current state | Client info in website form, email, and practice software; someone copies between them |
| Trigger event | Missed deadline due to missed onboarding task, client complaint about repeated info requests |
| Decision maker | Managing partner, operations director, office manager |
| Budget signal | Already paying for CRM + practice software but they don't talk to each other |
| Typical engagement | $3,000–$8,000 setup + $500–$1,500/month maintenance |

**Secondary ICP:** Small e-commerce operations with inventory, order, and customer data spread across Shopify, email, and spreadsheets.

---

## Division D — AI Customer Support

**Primary ICP:** Online businesses with repetitive customer questions and limited support staff.

| Attribute | Profile |
|-----------|---------|
| Industries | SaaS (micro), online course creators, membership sites, D2C e-commerce, local services with booking sites |
| Business size | 5–100 employees, $1M–$20M annual revenue |
| Pain point | Same questions asked repeatedly, slow response times, support owner is the founder |
| Current state | FAQ page nobody reads, support emails answered by founder evenings/weekends |
| Trigger event | Support tickets piling up, negative reviews about slow response, founder burned out |
| Decision maker | Founder, head of operations, customer success lead |
| Budget signal | Paying for customer support tools but still answering manually |
| Typical engagement | $2,500–$6,000 setup + $300–$800/month maintenance |

**Secondary ICP:** Local clinics (dental, vet, physio) with common patient questions (hours, insurance, booking).

---

## Division E — Premium Business Websites

**Primary ICP:** Service businesses whose current website does not generate leads or bookings.

| Attribute | Profile |
|-----------|---------|
| Industries | Any service business from Divisions A–D, plus contractors, consultants, coaches |
| Business size | 5–100 employees, $1M–$20M annual revenue |
| Pain point | Website looks outdated, not mobile-friendly, no contact/booking system, not appearing in search |
| Current state | DIY website (Wix/Squarespace) or nothing; no conversion tracking |
| Trigger event | Competitor launched better site, paid ads send traffic to non-converting site, rebrand |
| Decision maker | Owner, marketing manager |
| Budget signal | Willing to invest $3,000–$12,000 in a website that generates ROI |
| Typical engagement | $4,000–$15,000 one-time build + $200–$600/month hosting & maintenance |

---

## Cross-division qualification criteria

A lead is worth pursuing if they meet **at least 3** of:
- Has a clear, current pain point (not "just curious")
- Has budget or willingness to invest ($1,500+ for setup)
- Has decision-making authority
- Has a timeline (wants to start within 30–90 days)
- Uses or is willing to use modern tools (calendar, CRM, email marketing)
